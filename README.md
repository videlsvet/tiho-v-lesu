# «Тихо в лесу» — лендинг кофейни

Адаптивный одностраничный сайт на Next.js App Router, TypeScript, Tailwind CSS, Framer Motion и Lucide React.

## Требования

- Node.js 20.9 или новее
- npm 10 или совместимый менеджер пакетов

## Запуск локально

1. Распакуйте архив и откройте папку `tiho-v-lesu` в терминале.
2. Установите зависимости:

   ```bash
   npm install
   ```

3. Запустите режим разработки:

   ```bash
   npm run dev
   ```

4. Откройте http://localhost:3000.

## Проверка production-сборки

```bash
npm run lint
npm run build
npm start
```

## Перед публикацией

1. Укажите настоящий домен в переменной окружения `NEXT_PUBLIC_SITE_URL` (например, в `.env.local`):

   ```bash
   NEXT_PUBLIC_SITE_URL=https://ваш-домен.ru
   ```

2. Перепроверьте цены и ассортимент. В интерфейсе цены намеренно не указаны, поскольку публичные меню могут устаревать.
3. Проверьте график работы у владельца. Сайт отправляет посетителя к актуальным карточкам картографических сервисов, а не фиксирует часы работы.
4. Отзывы показаны в виде коротких цитат с указанием источника и ссылкой на карточку Яндекс Карт.
5. Галерея в этом проекте использует прямые URL публичных фотографий кофейни из карточки Яндекс Карт, поскольку страницы галереи 2ГИС не предоставили доступные прямые ссылки на изображения при подготовке проекта. Кнопки «Все фото в 2ГИС» ведут к галерее организации. Перед коммерческой публикацией проверьте право на использование фотографий; предпочтительно заменить изображения на файлы, переданные владельцем.
6. Пройдите сайт с мобильного устройства, проверьте внешние ссылки и актуальность контактных данных.

## Примечание по фактическим данным

Адрес и телефон взяты из публичных карточек организации. Список меню основан на публично доступном меню и не содержит цен. Отзывы сокращены, у каждой цитаты есть ссылка на карточку отзывов. Рейтинг и расписание не зашиты в сайт в виде постоянных цифр/значений, так как они могут меняться.
